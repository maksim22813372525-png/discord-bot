# Локальна AI-співрозмовниця для Discord

**Нова тестова версія `voice-2026.10.30.2`:** інструкція запуску — у [AI_WINDOWS.md](AI_WINDOWS.md). Розпізнавання російської, української й англійської; відповіді російською. Запуск: `start_ai.bat`. Виправлені помилковий вибір хінді й озвучення міркувань, додана коротка захисна пауза після відтворення. CPU-потоки вибираються за фізичними ядрами, модель залишається в RAM 30 хвилин. Нову швидкість і живий Discord ще потрібно перевірити на твоєму ПК.

Вже встановив? [Оновлення зі збереженням бібліотек і моделей](AI_WINDOWS.md#оновлення-вже-встановленого-бота). Додані GPU-розпізнавання, прогрів і утримання мовної моделі в RAM, готові короткі привітання, звертання Няшка/Альтушка/Альтушечка/Тянка, `/talk_test` для голосу та приватна `/talk_heard` з етапами й часом відповіді. Команди оновлюються також прямо на сервері.

Попередній режим випадкового повторення записів лишається доступним через `start.bat`; нижче його інструкція. Запускай лише один режим для того самого токена одночасно.

# Повторюшка мушка — голосовий бот

Заходить у твій голосовий канал, записує короткі фрази людей (до 8 секунд) і через випадкові інтервали відтворює оригінальні записи в тому самому войсі. Голос залишається голосом учасника: бот програє отримані Opus-пакети. Текстові повідомлення не читає. Перед початком публічно повідомляє про запис у каналі, де викликали команду.

## Запуск на твоєму ПК Windows

1. Закрий старе чорне вікно бота. Завантаж новий ZIP із гілки `codex/discord-bot-windows` через **Code → Download ZIP**. Розпакуй **весь архів у нову папку** через «Видобути все».
2. Потрібен установлений Python 3.10+ із галочкою **Add python.exe to PATH**. Він лише запускає підготовку.
3. Двічі натисни `start.bat`. Першого разу він автоматично завантажить портативний Node.js 24.22.2 з офіційного nodejs.org, перевірить його SHA-256 та встановить бібліотеки. Вручну встановлювати Node.js або FFmpeg не потрібно. Потрібен інтернет; права адміністратора не потрібні.
4. Коли з’явиться `Discord token:`, встав токен свого бота й натисни Enter. Символів не видно — це нормально. Токен не записується у файл; вводь його при кожному запуску. Не надсилай його в чат.
5. Дочекайся напису **«Онлайн»**. Зайди у звичайний голосовий канал сервера, а в текстовому каналі введи `/voice_on minimum:1 maximum:5`.
6. Поговоріть у войсі. Бот збереже короткі фрагменти й через 1–5 хвилин почне повторювати їх.

Залиш чорне вікно відкритим. Для зупинки закрий його або натисни Ctrl+C. ПК має залишатися увімкненим і не переходити у сон. Запускай лише одну копію бота. Підтримуються Windows x64 та ARM64. Запуск на Windows ще потрібно перевірити на твоєму ПК.

## Права у Discord

У бота мають бути **Дивитися канали (View Channels)**, **Надсилати повідомлення (Send Messages)**, **Приєднуватися (Connect)** та **Говорити (Speak)**. Перевір їх також у налаштуваннях конкретного голосового каналу. Адміністратор і Message Content Intent не потрібні.

Для бота з цієї розмови можна [оновити права через запрошення](https://discord.com/oauth2/authorize?client_id=1565152801372250242&permissions=3148800&integration_type=0&scope=bot%20applications.commands). Вибери той самий сервер — нового бота створювати не потрібно.

## Команди

- `/voice_on minimum:1 maximum:5` — зайти у твій войс, почати запис і повторення. Інтервали у хвилинах, від 1 до 1440, типово 1–5. Потрібне «Керування сервером».
- `/voice_off` — припинити запис, зупинити відтворення й вийти. Потрібне «Керування сервером».
- `/voice_clear` — видалити всі голосові записи сервера й поточні буфери. Нові фрази знову зберігатимуться, якщо бот лишається у войсі. Потрібне «Керування сервером».
- `/forget_me` — видалити свої записи та вимкнути записування себе на цьому сервері. Відмова зберігається після перезапуску.
- `/remember_me` — знову дозволити записувати свій голос.

Старі текстові `/echo_on`, `/echo_off`, `/echo_clear` замінюються голосовими командами після запуску. Оновлення списку команд у Discord може зайняти час.

## Записи та обмеження

До 100 фрагментів на сервер у `data/voice-clips.json` (аудіо та ID сервера, каналу й учасника). Довгі репліки обрізаються до 8 секунд, дуже короткі та тиша відкидаються. Короткі паузи приблизно зберігаються; це не розпізнавання речень, тому фраза може обірватися. Кожен учасник записується окремо. Інші боти і власне відтворення ігноруються; поки бот говорить, нові фрагменти не збираються.

Записи повторюються тільки в каналі, де їх записали. Після перезапуску вони лишаються, але автоматичний запис не починається — знову виконай `/voice_on`. Після втрати голосового з’єднання бот зупиняє запис; перевір повідомлення та повтори команду. Stage-канали не підтримуються. Папка даних задається через `BOT_DATA_DIR`. Старий `data/phrases.sqlite3`, якщо лишився від текстової версії, більше не використовується; його можна видалити вручну.

## Для розробки (Node.js 22.12+)

```bash
cd /workspace/discord-bot
npm ci
npm test
# DISCORD_TOKEN має бути заданий захищеним способом.
npm start
```

Залежності закріплені у `package-lock.json`; використовується `@discordjs/voice` 0.19.2 з підтримкою DAVE. Для встановлення потрібні registry.npmjs.org та nodejs.org (останній лише для Windows-запускача), для роботи — HTTPS/WebSocket Discord та вихідний UDP до голосових серверів Discord. Проксі лише для HTTP не забезпечує голосове підключення.

Локальні тести перевіряють Opus-пакети, паузи, обмеження, ізоляцію каналів, збереження після перезапуску, відмову від запису й очищення, скасування активних записів і відтворення через реальний аудіоресурс бібліотеки. Підключення до живого Discord потребує токена та тестового войсу; воно ще не перевірене.
