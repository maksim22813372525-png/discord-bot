# Discord бот-повторювач

Запам’ятовує нові текстові повідомлення людей у ввімкнених каналах. Через випадковий проміжок часу повторює випадкову збережену фразу з того самого каналу. Стару історію не завантажує, ботів і вебхуки ігнорує, вкладення не зберігає. Згадки не надсилають сповіщень.

## Налаштування Discord

1. Створи застосунок на https://discord.com/developers/applications і додай бота.
2. У розділі **Bot** увімкни **Message Content Intent**.
3. У **OAuth2 → URL Generator** вибери `bot` і `applications.commands`. Дозволи: **View Channels**, **Send Messages**. Запроси бота на сервер. Для гілок потрібен також **Send Messages in Threads**.
4. Збережи токен бота у змінній середовища `DISCORD_TOKEN`. Не публікуй токен і не додавай його в Git. Файл `.env` автоматично не завантажується.

## Запуск на Windows

Встанови Python, розпакуй архів і відкрий `start.bat`. Він створить локальне середовище, встановить залежності та попросить токен із прихованим введенням. Токен не зберігається на диску; його потрібно вводити при кожному запуску. Покрокова інструкція — у `WINDOWS.txt`.

## Запуск через термінал (Python 3.10+)

```bash
cd /workspace/discord-bot
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
# Задай DISCORD_TOKEN через захищені налаштування середовища.
.venv/bin/python bot.py
```

Бот працює, поки запущений процес. Для цілодобової роботи потрібна машина, що не вимикається. Після перезапуску налаштування й фрази відновлюються з SQLite; відлік випадкового інтервалу починається заново. Запускай лише один процес із цією базою. Файл бази: `data/phrases.sqlite3`; іншу папку можна задати через `BOT_DATA_DIR`.

## Команди

- `/echo_on minimum:30 maximum:180` — увімкнути в поточному каналі. Інтервал у хвилинах, від 1 до 10080; за замовчуванням 30–180. Потрібне право «Керування сервером».
- `/echo_off` — припинити збереження й повторення в поточному каналі. Потрібне право «Керування сервером».
- `/echo_clear` — видалити всі фрази поточного каналу. Потрібне право «Керування сервером».
- `/forget_me` — видалити свої збережені фрази поточного каналу. Нові повідомлення після цього можуть знову зберігатися.

Зберігаються останні 1000 фраз на канал. Увімкнення публічно повідомляє учасникам про збереження. Видалення повідомлення у Discord не видаляє його копію з бази: використовуй команди очищення. Якщо база порожня, бот чекає наступного інтервалу. Slash-команди після першого запуску можуть з’явитися із затримкою.

## Перевірка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Для роботи потрібен доступ до Discord HTTPS API (`discord.com`) і WebSocket gateway (`gateway.discord.gg`). Повноцінна перевірка підключення потребує справжнього токена й тестового сервера.
